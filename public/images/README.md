# Images

Replace these files with your own — no code changes needed.

- `profile.jpg` — your profile photo (square works best). Until it exists, the hero shows an initials placeholder.
- `projects/` — project screenshots. Reference them in `src/data/portfolio.ts` as `image: "/images/projects/my-app.jpg"`.
- `certificates/` — certificate images, referenced as `image: "/images/certificates/my-cert.jpg"`.
- `icons/` — any custom icons you want to use.

Your CV lives at `public/resume.pdf` — replace that file to update the Resume button.
